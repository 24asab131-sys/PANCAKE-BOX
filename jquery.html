jQuery

Una biblioteca de JavaScript que facilita la creación de páginas web interactivas.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript creada para facilitar el desarrollo de páginas web. Permite realizar acciones sobre los elementos HTML de una página utilizando menos código.

Fue muy utilizada porque simplificaba tareas como modificar elementos, responder a eventos, crear efectos y realizar solicitudes a servidores.

¿Por qué fue creado?

jQuery fue creado para hacer más sencillo el trabajo con JavaScript y evitar que los desarrolladores tuvieran que escribir mucho código para realizar tareas comunes.

⚡ Menos código

Permite realizar algunas acciones con instrucciones más cortas.

🎨 Efectos

Facilita la creación de efectos visuales en una página.

🖱️ Eventos

Permite trabajar fácilmente con acciones como clics.

La sintaxis $()

Una de las características más conocidas de jQuery es el uso del símbolo $. Se utiliza para seleccionar elementos HTML y trabajar con ellos. 

$("#titulo")

En este ejemplo, #titulo selecciona el elemento que tiene el identificador titulo. 

$("#boton").click(function() {
    alert("¡Hola!");
});

jQuery vs JavaScript moderno

Característica jQuery JavaScript moderno
Sintaxis Puede ser más corta Utiliza funciones propias del lenguaje
Uso Facilita tareas comunes Permite trabajar directamente con el navegador
Velocidad Necesita cargar la biblioteca No necesita una biblioteca adicional
Actualidad Se utiliza en algunos proyectos Es la opción principal para proyectos modernos

Ventajas y desventajas

✅ Ventajas

Su sintaxis puede ser sencilla, facilita algunos efectos y permite trabajar fácilmente con elementos HTML y eventos.

❌ Desventajas

Es necesario cargar una biblioteca adicional y muchas funciones que antes requerían jQuery ahora pueden realizarse directamente con JavaScript.

Ejemplo: fadeIn()

El efecto fadeIn() permite mostrar progresivamente un elemento.

¡Hola! Esta caja apareció con un efecto.

Ejemplo: slideToggle()

slideToggle() permite mostrar u ocultar un elemento utilizando un efecto deslizante.

Esta información puede aparecer o desaparecer.

Ejemplo de código jQuery

$("#boton").click(function() {
    $("#mensaje").slideToggle();
});

En este ejemplo, cuando el usuario hace clic en el botón, el elemento con el identificador mensaje aparece o desaparece utilizando un efecto deslizante.
