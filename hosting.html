Hosting & Dominios

Descubre cómo una página web llega desde nuestro computador hasta Internet.

¿Cómo llega una página web a Internet?

Cuando creamos una página web en nuestro computador, los archivos necesitan estar almacenados en un servidor para que otras personas puedan acceder a ellos desde Internet.

💻

Creamos los archivos HTML, CSS y JavaScript.

➡️
☁️

2. Hosting

Los archivos se almacenan en un servidor.

➡️
🌐

3. Internet

Las personas pueden visitar nuestra página.

¿Qué es Web Hosting?

El Web Hosting o alojamiento web es un servicio que permite almacenar los archivos de una página web en un servidor conectado a Internet.

Gracias al hosting, los usuarios pueden acceder a una página utilizando un navegador desde diferentes dispositivos.

Tipos de Hosting

🏠 Hosting compartido

Varios sitios web utilizan los recursos de un mismo servidor. Es una opción sencilla y económica.

🖥️ VPS

Un servidor físico se divide en varios servidores virtuales. Cada uno tiene recursos asignados.

☁️ Cloud Hosting

Utiliza varios servidores conectados para ofrecer recursos y mayor flexibilidad.

¿Qué es un dominio?

Un dominio es la dirección que utilizan las personas para encontrar un sitio web en Internet.

Por ejemplo, una página puede tener una dirección como:

pancakebox.com

Partes de un dominio

pancakebox

Nombre elegido para identificar el sitio.

.com

Extensión o dominio de nivel superior.

¿Qué es un TLD?

TLD significa Top-Level Domain, es decir, dominio de nivel superior. Es la parte final de una dirección web.

.com

Muy utilizado por sitios comerciales y proyectos generales.

.org

Comúnmente utilizado por organizaciones.

.edu

Relacionado con instituciones educativas.

¿Qué es un subdominio?

Un subdominio es una parte adicional que se coloca antes del dominio principal y permite organizar diferentes secciones de un sitio web.

blog.pancakebox.com

En este ejemplo, blog es el subdominio.

¿Qué es el DNS?

El DNS, o Sistema de Nombres de Dominio, permite relacionar nombres de dominio fáciles de recordar con las direcciones que utilizan los servidores.

Cuando se configura un dominio, los cambios pueden tardar un tiempo en actualizarse y llegar a diferentes servidores de DNS. A este proceso se le conoce como propagación DNS.

➡️
4

El usuario puede acceder al sitio.
