TECNOLOGÍA WEB

JavaScript

El lenguaje que permite agregar interactividad y comportamiento a las páginas web.

CONCEPTOS BÁSICOS

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. Permite que una página pueda responder a las acciones que realiza el usuario.

Por ejemplo, JavaScript puede utilizarse para mostrar mensajes, cambiar contenido, validar formularios, realizar cálculos y crear efectos dentro de una página.

HTML

Se encarga de crear la estructura y el contenido de una página web.

CSS

Se utiliza para darle diseño, colores, tamaños y estilos a la página.

JavaScript

Permite agregar interactividad y comportamiento a los elementos.

ELEMENTOS IMPORTANTES

Variables y funciones

Variables

Una variable permite guardar información que puede utilizarse posteriormente dentro de un programa. 

let nombre = "Pancake Box";

Funciones

Una función es un bloque de código que realiza una tarea específica y puede ejecutarse cuando sea necesario. 

function saludar() {
    alert("¡Bienvenido!");
}

INTERACCIÓN

Eventos en JavaScript

Los eventos permiten que JavaScript responda a las acciones realizadas por el usuario.

Click

Se ejecuta cuando el usuario hace clic sobre un elemento.

Hover

Puede utilizarse para detectar cuando el usuario coloca el cursor sobre un elemento.

EJEMPLO PRÁCTICO

JavaScript en acción

El siguiente botón utiliza JavaScript para cambiar el mensaje que aparece en pantalla.

Aquí aparecerá un mensaje.

¿Cómo funciona?

Primero se selecciona el botón mediante su identificador. Después se agrega un evento click. Cuando el usuario presiona el botón, JavaScript cambia el texto del mensaje. 

const boton = document.getElementById("botonMensaje");

boton.addEventListener("click", function() {

    document.getElementById("mensaje").textContent =
        "¡Gracias por visitar Pancake Box! 🥞";

});
