JSON

Una forma sencilla y organizada de almacenar e intercambiar información.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para almacenar y transmitir información de una manera sencilla y organizada.

JSON es muy utilizado en páginas web y aplicaciones para enviar información entre un servidor y un navegador.

¿Por qué se utiliza como estándar?

JSON se utiliza ampliamente porque es fácil de leer y escribir tanto para las personas como para los programas.

Además, puede utilizarse con diferentes lenguajes de programación, por lo que facilita el intercambio de información entre sistemas.

Clave y valor

Los datos en JSON se organizan principalmente mediante pares de clave y valor. 

{
    "producto": "Berry Box",
    "precio": 3.50,
    "disponible": true
}

En este ejemplo, producto, precio y disponible son las claves. Sus respectivos datos son los valores.

Objetos y arrays

📦 Objeto

Un objeto contiene información organizada mediante claves y valores. 

{
    "nombre": "Choco Box",
    "precio": 4.00
}

📋 Array

Un array permite guardar varios elementos dentro de una lista. 

[
    "Berry Box",
    "Choco Box",
    "Banana Sweet"
]

JavaScript vs JSON

Aunque JSON está basado en la sintaxis de los objetos de JavaScript, no son exactamente lo mismo.

JavaScript JSON
Es un lenguaje de programación. Es un formato para representar datos.
Puede contener funciones. No contiene funciones.
Puede ejecutar instrucciones. Se utiliza principalmente para almacenar e intercambiar información.

Ejemplo visual

Observa la diferencia entre un objeto de JavaScript y un texto escrito en formato JSON.

JavaScript

const producto = {
    nombre: "Berry Box",
    precio: 3.50
};

JSON

{
    "nombre": "Berry Box",
    "precio": 3.50
}

¿Cómo utilizan JSON las aplicaciones web?

Las aplicaciones web pueden utilizar JSON para enviar y recibir información entre el navegador y un servidor.

Por ejemplo, una página de una tienda puede solicitar al servidor información sobre sus productos. El servidor puede responder enviando esos datos en formato JSON.

JSON en Pancake Box 🥞

En una página como Pancake Box, JSON podría utilizarse para guardar información de nuestros productos. 

{
    "nombre": "Banana Sweet",
    "precio": 3.75,
    "ingrediente": "Banana",
    "disponible": true
}

De esta manera, una aplicación podría recibir fácilmente información sobre el producto y mostrarla en la página.
